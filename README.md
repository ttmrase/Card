# カードフォージ (CardForge)

プレイヤーが自分でカードを作り、そのカードで遊べる Android 用カードゲームアプリ。
属性・種族・カテゴリといったカードの構成要素そのものから、効果テキストの中身まで、
すべてアプリ内で作成・編集できる。

## APK の入手

このリポジトリには GitHub Actions のワークフロー (`.github/workflows/android.yml`) が
入っている。ブランチに push すると自動でビルドが走り、Actions の実行ページの
**Artifacts** から `cardforge-apk`（`app-debug.apk` と `app-release.apk`）を
ダウンロードできる。`app-debug.apk` をそのまま端末に入れれば動く。

手元でビルドする場合は Android SDK を入れて次を実行する。

```bash
./gradlew assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
./gradlew test                 # ルールとカードテキストのテスト
```

必要環境: JDK 17、Android SDK (compileSdk 34)。対応端末は Android 8.0 (API 26) 以上。

## ゲームのルール

- お互いのライフは **8000** ポイント。先に 0 になった方が負け。
- **相手フィールドにモンスターがいる限り、プレイヤーへの直接攻撃はできない。**
- 通常召喚のリリース（生け贄）は、**レベル4以下は不要／5〜6は1体／7以上は2体**。
  通常召喚（セット含む）は1ターンに1度。
- **魔法カード**は自分のターンのメインフェイズにのみ発動できる。
  魔法・罠ゾーンに伏せたあとでも、自分のターンなら発動できる。
- **罠カード**は伏せたターンには発動できない。
  次のターン以降は、相手ターン・自分ターンを問わず発動できる。
- 伏せ罠は、相手の「カードの発動」「召喚」「攻撃宣言」に対して割り込める。
  無効化する効果を持つ罠なら、それらを無効にして破壊する。
- フェイズはドロー → メイン1 → バトル → メイン2 → エンド。最初のターンにバトルフェイズは無い。
- エンドフェイズに手札が6枚を超えていたら、超えた分を捨てる。
- デッキが尽きた状態でドローするプレイヤーは敗北する。

対戦形式は **AI との対戦**と、1台の端末を回して遊ぶ **2人交代（ホットシート）** の2つ。

## カードの作り方

カードは3種類。

| 種類 | 持つ要素 |
| --- | --- |
| モンスター | レベル / 属性 / 種族 / カテゴリ / 攻撃力 / 守備力 |
| 魔法 | カテゴリ（魔法・罠ゾーンで使用、自分ターンのみ） |
| 罠 | カテゴリ（魔法・罠ゾーンで使用、伏せた次のターン以降） |

カード名とイラスト（端末から選択）は自由に設定できる。取り込んだ画像はアプリ内部に
コピーされるので、元の画像を消してもカードのイラストは失われない。

### 効果テキストの自由記述

効果を持つカードは、**【場所】【条件】【コスト】【効果】** の4要素を持つ。

- **場所** … そのカードを発動できる場所（手札／フィールド／墓地）。
  魔法・罠で省略した場合は「フィールドで発動」になる。
- **条件** … 発動に必要な状況。省略するとどんな状況でも発動できる。
- **コスト** … 発動に必要な支払い。省略するとノーコストで発動できる。
- **効果** … 実際に起こること。

効果は ①②③… と区切って、1枚のカードに複数持たせられる。
**効果番号より前**に書いた【場所】【条件】【コスト】はそのカードの全ての効果に掛かり、
**効果番号の直後**に書いたものはその番号の効果にだけ掛かる。

効果の1文は「主語・目的語・修飾語・述語」を選択肢から選んで組み立てる。

```
【誰の】【どの領域の】【どんな条件のカード】【何枚】を【どう選んで】【どうする】
   相手     フィールドの   闇属性モンスター     1体      選んで      破壊する
```

選べる述語は、破壊 / 除外 / 手札に加える / 墓地へ送る / デッキに戻す / 特殊召喚 /
攻撃力・守備力の変化 / 表示形式の変更 / ドロー / ダメージ / ライフ回復 /
手札を捨てさせる / デッキから墓地へ送る / 発動の無効化。

絞り込みの条件には、カードの種類・属性・種族・**カテゴリ**・レベル・攻撃力・守備力・
表示形式・カード名が使える。組み立てている途中の文はその場で日本語に整形して表示される。

### カテゴリ

すべてのカードに自由な「カテゴリ」を付けられる。カテゴリは効果テキストから参照できるので、
テーマデッキを丸ごと自作できる。

> 例：カテゴリを「アララギ」にしておくと、
> 『自分のデッキの「アララギ」モンスター1体を選んで自分のモンスターゾーンに
> 表側攻撃表示で特殊召喚する。』という効果が書ける。

属性・種族・カテゴリは「属性・種族・カテゴリ」画面でいつでも追加・改名・削除できる。
削除した場合、それを参照していたカードからは自動的に外れる。

## 構成

```
app/src/main/java/com/cardforge/
├── model/      カード・効果 DSL のデータ定義（kotlinx.serialization でJSON化）
│   ├── Enums.kt      プレイヤー・領域・比較・表示形式などの選択肢
│   ├── Effect.kt     場所・条件・コスト・効果と、対象指定 (CardScope)
│   └── Library.kt    カード / デッキ / マスターデータ
├── text/       構造化された効果データを日本語のカードテキストに整形
├── data/       JSON 永続化、イラストの取り込み、初期サンプルデータ
├── game/       デュエルのルール処理
│   ├── GameModels.kt 盤面の状態
│   ├── GameEngine.kt 召喚・戦闘・効果解決・ターン進行
│   ├── Interaction.kt プレイヤーへの問い合わせ口
│   └── Ai.kt         AI の思考
└── ui/         Jetpack Compose の画面
```

エンジンがプレイヤーに選択を求めるときは `Interaction` 越しに suspend 関数で待つ。
UI はそこにダイアログを出し、AI は自動で答える。どちらも同じルール処理を通る。

## テスト

`app/src/test/` にルールとカードテキストのテストがある。

```bash
./gradlew test
```

- `GameRulesTest` … ライフ8000、リリース数、直接攻撃の制限、戦闘ダメージ計算、
  罠の発動タイミング、魔法の発動タイミング、場所・条件・コストによる発動制限、
  カテゴリ指定、ライフ0とデッキ切れによる決着。
- `CardTextTest` … 効果テキストの整形と JSON の往復。
- `DuelSimulationTest` … AI 同士のデュエルを通しで回し、盤面が壊れないことを確認する。
